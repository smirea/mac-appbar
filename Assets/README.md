# Assets

`AppStoreIcon.svg` is the SVG Logos `Apple App Store` icon fetched through Iconify. `AppStoreCompass.svg` extracts the bare compass glyph from that source for the normal menu bar icon, and `AppStoreCompassCutout.svg` inverts the alpha mask for the unread state.

Source: `https://api.iconify.design/logos/apple-app-store.svg`

The shadcn icon listing identifies this icon as CC0. The generated app icon uses the same glyph on a plain monochrome background. The menu bar PNGs are rendered as template images, so macOS controls the visible color.
